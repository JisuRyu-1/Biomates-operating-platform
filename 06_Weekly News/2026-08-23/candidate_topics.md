## B. AI for Work 후보 4개 (workflow 자동화 중심으로 재검색)

> 가이드 3절 "리서치 우선순위" 반영: 모델 성능·가격 뉴스보다 실제
> 업무 단계를 줄여주는 기능 위주로 재구성.

### 1. Perplexity Comet Agent — "Personal Computer"(Mac) 기능
- **WHAT**: Comet Agent가 Mac에서 로컬 파일 편집·브라우저 작업을 대신
  수행하는 "Personal Computer" 기능을 추가. 기본 모델도 Claude
  Sonnet 4.6(프리미엄은 Opus)으로 전환.
- **SOURCE**: 2차 보도 다수 (Tier 2/3) — Perplexity 공식 changelog
  대조 필요
- **평가**: **가장 강한 workflow 자동화 사례** — 리서치→파일 정리까지
  대행. WATCH OUT(로컬 파일 접근 리스크)이 특히 중요.

### 2. Microsoft Copilot Chat — Claude 모델 선택 지원
- **WHAT**: 복잡한 분석·문서 이해·구조화된 콘텐츠 생성 시 Copilot
  Chat에서 Claude를 모델로 선택 가능해짐.
- **SOURCE**: Microsoft Learn 릴리즈 노트 경로로 추정 (Tier 1 후보,
  공식 문서 대조 필요)
- **평가**: Microsoft 365 사용 기업 다수에 즉시 적용 가능 —
  Practicality·Accessibility 높음.

### 3. Notion AI — @mention으로 AI 에이전트를 팀원처럼 호출
- **WHAT**: Notion에서 AI 에이전트를 @mention으로 호출해 외부 도구
  데이터 가져오기·리서치 요약·문서 초안 작성을 맡길 수 있게 됨(활동은
  audit log로 추적).
- **SOURCE**: 2차 보도 경로 (Tier 2/3) — Notion 공식 발표 대조 필요
- **평가**: Product/PM 업무 workflow 변화 스토리 구성이 쉬움.

### 4. Claude Developer Platform — Managed Agents의 GitHub 기반 Skills 자동 로드
- **WHAT**: Claude Managed Agents 세션이 GitHub 저장소를 마운트하면
  `.claude/skills` 디렉토리의 skill들을 세션 시작 시 자동으로
  인식해서 사용. 세션 예산·advisor 모델·데이터 레지던시 등 관리
  기능도 함께 추가.
- **SOURCE**: Releasebot(Anthropic 업데이트 트래커), 2026년 8월 — Tier
  2/3, Anthropic 공식 changelog 대조 필요
- **평가**: **반복되는 다단계 리뷰 workflow를 팀 단위로 표준화**하는
  사례 — RA/QA가 "규제 대응 체크리스트" 같은 skill을 저장소로
  관리하고 여러 리뷰에 재사용하는 use case로 연결 가능. 다만 대상이
  다소 기술 지향적이라 medtech use case 설명을 신경 써야 함.
