# LinkedIn AI at Work Survey Project Guide

> **Project goal**\
> LinkedIn Poll을 이용해 사람들이 ChatGPT/Codex, Claude, Gemini, Copilot
> 등 생성형 AI를 **실제 업무에서 어떻게 사용하고 있으며, AI가 업무
> 방식을 어디까지 바꾸고 있는지** 단계적으로 조사한다.\
> 한 번에 긴 설문을 요청하기보다 짧은 Poll → 댓글 → 후속 Poll → 사례
> 수집 → 분석 → 카드뉴스의 흐름으로 발전시킨다.

------------------------------------------------------------------------

## 1. 프로젝트에서 알고 싶은 것

이 프로젝트는 단순한 **"어떤 AI가 가장 인기 있는가?"** 조사가 아니다.

궁극적으로 다음 질문에 답하는 것이 목표다.

1.  사람들은 AI를 업무에서 **어디까지** 활용하고 있는가?
2.  어떤 AI Tool을 실제로 많이 사용하는가?
3.  AI가 업무에 만든 가장 큰 변화는 무엇인가?
4.  단순 Q&A를 넘어 **Create / Integrate / Automate** 단계까지 가고
    있는가?
5.  실제로 다른 사람에게 공유할 만한 좋은 Use Case는 무엇인가?

핵심 관점:

> **Tool → Use Case → Maturity → Impact → Real Practice**

------------------------------------------------------------------------

# 2. 조사 방식

긴 설문 하나를 배포하지 않는다.

대신 LinkedIn에서 **짧은 Poll을 순차적으로 게시**하고, 각 Poll의
댓글에서 실제 사례와 맥락을 수집한다.

``` text
STEP 1
AI 활용 수준
    ↓
STEP 2
주요 AI Tool
    ↓
STEP 3
업무 변화
    ↓
STEP 4
구체적 Use Case
    ↓
STEP 5
결과 분석
    ↓
STEP 6
Card News / Insight Post
```

각 단계의 결과가 다음 질문을 결정하도록 한다.

------------------------------------------------------------------------

# 3. STEP 1 --- AI를 어디까지 활용하고 있는가?

## Research Question

> 생성형 AI를 업무에서 어느 수준까지 활용하고 있는가?

제품 이름보다 **활용 수준**을 먼저 묻는다.

## LinkedIn Poll

### Question

**여러분은 생성형 AI를 업무에서 주로 어디까지 활용하고 계신가요?**

### Options

-   🔎 검색·요약·번역
-   🧠 분석·기획·리서치
-   🛠 결과물·코드 제작
-   ⚙️ 자동화·Agent 활용

## Post Copy Draft

ChatGPT, Claude, Gemini, Copilot 등 생성형 AI가 빠르게 업무에 들어오고
있는데, 실제로 사람들이 **어디까지 활용하고 있는지** 궁금해졌습니다.

단순 검색이나 문서 작성부터, 분석·리서치, 실제 결과물 제작, 반복 업무
자동화까지 활용 방식도 꽤 다른 것 같습니다.

현재 본인의 업무 방식과 **가장 가까운 하나**를 선택해 주세요.

특히 어떤 Tool을 어떤 업무에 사용하고 있는지 댓글로 공유해 주시면 후속
조사에서 실제 Use Case도 함께 살펴보겠습니다.

## What to Observe

투표율뿐 아니라 댓글을 함께 기록한다.

특히 다음 표현을 찾는다.

-   "저는 사실 2번과 3번 사이입니다."
-   "이 업무에서는 4번까지 사용합니다."
-   "Tool마다 다르게 사용합니다."
-   구체적인 업무 사례
-   AI 활용의 한계나 불편함

이러한 댓글은 STEP 2--4의 질문 설계에 사용한다.

------------------------------------------------------------------------

# 4. AI Maturity Framework

STEP 1 결과는 다음 네 단계로 해석한다.

## LEVEL 1 --- ASK

> **AI에게 물어본다**

검색 / 번역 / 요약 / 문장 작성

------------------------------------------------------------------------

## LEVEL 2 --- ANALYZE

> **AI와 함께 생각한다**

Research / 비교 / 분석 / 기획 / 문제 구조화

------------------------------------------------------------------------

## LEVEL 3 --- CREATE

> **AI와 실제 결과물을 만든다**

PPT / Report / Data Analysis / Code / Prototype / Diagram

------------------------------------------------------------------------

## LEVEL 4 --- INTEGRATE & AUTOMATE

> **AI에게 Workflow의 일부를 맡긴다**

업무 시스템 연결 / Agent / 반복 업무 자동화 / Tool 구축

------------------------------------------------------------------------

이 framework는 절대적인 능력 평가가 아니다.

업무 성격에 따라 필요한 수준이 다르며, 목적은 **현재 AI가 업무
workflow의 어디에 들어와 있는지 관찰하는 것**이다.

------------------------------------------------------------------------

# 5. STEP 2 --- 어떤 AI를 가장 많이 사용하는가?

STEP 1 이후 Tool 사용 현황을 확인한다.

## Research Question

> 실제 업무에서 가장 자주 사용하는 생성형 AI는 무엇인가?

## Poll Draft

**업무에서 가장 자주 사용하는 AI Tool은 무엇인가요?**

-   ChatGPT / Codex
-   Claude / Claude Code
-   Gemini 계열
-   Copilot / 기타

## Comment Prompt

> 선택지 제한 때문에 모든 Tool을 넣지는 못했습니다. Cursor, Perplexity,
> NotebookLM 등 다른 Tool을 주로 사용하신다면 댓글로 알려주세요.

## Analysis

단순 market share처럼 해석하지 않는다.

LinkedIn의 개인 network 특성상 결과는 대표성 있는 시장조사가 아니다.

따라서:

> "응답자 중 X%"

라고 표현하고,

> "전체 AI 사용자의 X%"

라고 일반화하지 않는다.

# 6. STEP 3 --- AI가 무엇을 바꿨는가?

## Research Question

> AI 사용의 가장 큰 실제 효과는 무엇인가?

## Poll Draft

**AI가 실제 업무에서 만든 가장 큰 변화는 무엇인가요?**

-   ⏱ 업무 시간 단축
-   ✨ 결과물 품질 향상
-   🛠 혼자 할 수 있는 일 확대
-   🔄 반복 업무 감소

### Why this matters

특히 다음 두 가지를 구분해서 본다.

### Productivity

> 같은 일을 더 빠르게 한다.

vs.

### Capability Expansion

> 예전에는 하지 못했던 일을 직접 한다.

예:

``` text
Before
개발자에게 요청
      ↓
요구사항 설명
      ↓
대기
      ↓
Tool 제작

After
AI + Coding Agent
      ↓
직접 Prototype
```

AI가 단순 efficiency tool인지 **individual capability multiplier**인지
확인하는 핵심 질문이다.

# 7. STEP 4 --- 실제 Use Case 수집

앞의 Poll 결과 이후에는 투표보다 **사례 수집**으로 전환한다.

## Post Question

**다른 사람에게도 추천하고 싶은 AI 업무 활용법이 있나요?**

아래 형식으로 댓글을 요청한다.

``` text
Tool:
Use Case:
Before:
After:
```

예:

``` text
Tool: ChatGPT

Use Case:
여러 regulatory document 비교

Before:
문서를 하나씩 열어 requirement를 수동으로 정리

After:
문서를 함께 분석해서 차이점과 확인할 항목을 먼저 정리
```

또는:

``` text
Tool: Cursor

Use Case:
간단한 내부 데이터 Tool 제작

Before:
개발자에게 요청하거나 Excel로 수작업

After:
직접 작은 Web Tool로 구현
```

# 8. STEP 5 --- 좋은 사례 선정

수집된 Use Case는 다음 기준으로 평가한다.

  기준          질문
  ------------- -------------------------------------
  Practical     실제 업무에 바로 적용 가능한가?
  Repeatable    다른 사람도 따라 할 수 있는가?
  Impact        시간/품질/Capability 변화가 있는가?
  Novel         단순 번역·요약 이상의 활용인가?
  Explainable   짧게 설명할 수 있는가?

좋은 사례 3--5개를 선정한다.

# 12. 해석 시 주의사항

이 조사는 학술적 survey가 아니라 **LinkedIn community pulse check**에
가깝다.

따라서 결과를 과도하게 일반화하지 않는다.

권장 표현:

> "이번 LinkedIn Poll에 참여한 응답자 가운데..."

> "작은 표본이지만 흥미로운 패턴은..."

> "제 LinkedIn network를 대상으로 한 informal survey에서는..."

피해야 할 표현:

> "직장인의 60%가..."

> "업계의 70%가..."

표본 특성과 selection bias를 항상 고려한다.

# 14. 프로젝트 운영 원칙

## 1. 한 번에 하나만 묻는다

설문 참여자가 고민해야 하는 시간을 최소화한다.

## 2. 결과를 다음 질문으로 연결한다

각 Poll이 독립적인 게시물이 아니라 하나의 이야기처럼 이어져야 한다.

## 3. Poll보다 댓글이 더 중요할 수 있다

숫자는 **What**을 보여주고 댓글은 **Why**를 보여준다.

## 4. 예상과 다른 결과를 환영한다

처음 세운 AI maturity framework에 결과를 억지로 맞추지 않는다.

## 5. 마지막에는 유용한 것을 돌려준다

조사 결과를 단순 발표하지 않고:

-   실제 Use Case
-   따라 할 수 있는 Workflow
-   추천 Tool
-   실무 Tip

등으로 다시 community에 공유한다.

# 15. Success Criteria

이 프로젝트의 성공은 투표 수만으로 판단하지 않는다.

성공적인 결과는:

-   AI 활용 수준에 대한 실제 분포를 확인했다.
-   예상하지 못했던 Use Case를 발견했다.
-   다른 사람이 따라 해볼 만한 사례를 확보했다.
-   AI가 productivity와 capability를 어떻게 바꾸는지 관찰했다.
-   후속 논의를 이어갈 사람들을 발견했다.
-   최종적으로 유용한 콘텐츠로 다시 공유했다.

궁극적인 질문은 다음과 같다.

> **"우리는 AI를 더 많이 쓰고 있는가?"가 아니라\
> "AI 때문에 실제 일하는 방식이 어떻게 달라지고 있는가?"**
